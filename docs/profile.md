## Case Studies

> Botlune and Some Stupid FPS Game are marked as case studies but still need a problem / solution / impact write-up.

### UploadiT
- **Problem:** Finding a specific answer across a stack of documents means reading through all of them by hand.
- **Solution:** A RAG pipeline built with FastAPI, Pinecone, and Next.js. Uploaded documents are converted into embeddings, so users can ask questions in natural language and get answers grounded in their own files.
- **Impact:**
  - Contextual answers through semantic search instead of keyword matching
  - Supports PDF, DOCX, and TXT
  - Session-based isolation keeps every user's data private
  - Automatic expiry means no documents are kept longer than needed
- **Tech:** Python, FastAPI, Pinecone, Next.js, TypeScript, Tailwind CSS

### CI4 CMS Starter
- **Problem:** Starting a content-driven site on CodeIgniter 4 means rebuilding authentication, permissions, and admin tooling every time, with no modern frontend setup out of the box.
- **Solution:** A reusable starter kit that combines CodeIgniter 4 and Tailwind CSS, with complete authentication, role-based access control, and an admin dashboard already in place.
- **Impact:**
  - Faster kick-off for new content-driven projects
  - Secure, role-based user management out of the box
  - Modern, responsive UI with Tailwind CSS
  - SEO-friendly structure with clean URLs
- **Tech:** PHP, CodeIgniter 4, MySQL, Tailwind CSS, CKEditor 5

### HR Portal — Stratacache
- **Problem:** Stratacache's existing HR tools were slow and hard to use, which made everyday tasks like managing employee data frustrating.
- **Solution:** A custom HR portal with a reactive Vue.js frontend (Vuex for state) and a Laravel backend, plus caching and optimized database queries.
- **Impact:**
  - 40% reduction in page load time
  - 50% improvement in backend query performance
  - 20% increase in user engagement
  - Real-time notifications for HR events
- **Tech:** Vue.js, Vuex, Laravel, MySQL, REST APIs
